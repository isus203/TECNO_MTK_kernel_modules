# TECNO MTK Kernel Modules

Kernel modules for TECNO MediaTek platforms.

This repository follows the MiCode-style layout: the default `main` branch is an index and each TECNO source release is stored in its own branch.

| Branch | Device | Android version | SoC | Kernel | Kernel Name | Base tag | Link |
|---|---|---|---|---|---|---|---|
| android15_kernel_MT6878 | POVA 7 Pro 5G, POVA 7 5G, CAMON 40 Pro 5G | Android 15 | MT6878 | 6.1.157 | Curry Ramen | MTK | [android15_kernel_MT6878](https://github.com/isus203/TECNO_MTK_kernel_modules/tree/android15_kernel_MT6878) |
| android15_kernel_MT6897 | POVA 7 Ultra 5G, CAMON 40 Premier 5G | Android 15 | MT6897 | 6.1.157 | Curry Ramen | MTK | [android15_kernel_MT6897](https://github.com/isus203/TECNO_MTK_kernel_modules/tree/android15_kernel_MT6897) |

## Source

The branches are generated from source archives published on the official TECNO Open Source portal. Kernel version and `NAME` are read from the kernel `Makefile` when available.
